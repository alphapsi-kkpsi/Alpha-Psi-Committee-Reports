# Alpha Psi Committee Reports

Static Firebase web app for Kappa Kappa Psi Alpha Psi Chapter committee reports.

## Features
- One-time first Admin setup through the website
- Admin-managed committees, chapter meeting dates, and Executive Member accounts
- Committee-level access control
- Preset meeting dates
- Standard committee report form
- Admin missing/submitted report dashboard
- Firebase Authentication + Firestore

## Hosting
Designed for GitHub Pages.
